# CreatLab releases

Official downloads of the **CreatLab desktop app** for Windows and Mac. The CreatLab source code is private; only the installers are published here.

**Latest version:** https://github.com/Basill07/creatlab-releases/releases/latest

| System | File |
|---|---|
| Windows (64-bit) | `CreatLab-Setup.exe` |
| Mac, Apple silicon | `CreatLab-mac-arm64.dmg` |
| Mac, Intel | `CreatLab-mac-x64.dmg` |

## Notes
- Early builds are **not code-signed**. Windows may show SmartScreen ("More info" → "Run anyway"). On a Mac, right-click the app and choose Open, or use System Settings → Privacy & Security → Open Anyway.
- The app updates itself from the releases in this repository.
- Everything you do in CreatLab also works in the browser at https://creatlab.cloud.

Questions or problems: use the feedback page inside CreatLab ("Help Shape CreatLab").
